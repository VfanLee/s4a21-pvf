# 称号缺失排查与修复

返回 [数据库目录](README.md)；关联字段见 [表结构速查](tables.md)，修改前按 [手动维护流程](manual-workflow.md)备份和停服。
本页区分任务完成、成就计数和实际称号实例，所有数据修改仅由你执行。

## 成就完成但称号缺失

- 分别检查交任务记录、`p1/p2/p3` 剩余计数、称号簿实例和背包/穿戴实例。
  三个计数全零不证明称号实例存在；`p4` 不参与参考服务端的完成判断，客户端含义未确认，保留原值。
- `TitleBookMutationService` 仅在未完成变为 `p1/p2/p3` 全零时触发称号创建。
  已全零的记录不自动补发；不存在的成就记录按任务检查次数初始化，缺省为 1。
- 如果你决定通过重做修复，先核对前置任务和成就包装任务，备份、停服后在同一事务中
  恢复前置任务完成值与成就初始剩余状态。只将对应前置完成值改为 0，不删除记录；
  成就初始值必须按任务配置和初始化代码确定，不套击杀进度位运算。
- 保留其他前置条件、`p4`、排序和已有实例；不伪造已接任务、激活标识或 BLOB。
  重新启动后通过正常接取、完成和交任务流程，核对称号实际到账。
