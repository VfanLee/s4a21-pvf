# 数据库维护参考

数据库表结构与手动维护场景按主题分开记录，供 PVF 开发者查阅。
**数据库只能由你修改；AI 可以参考服务端代码讲解和提供示例，不得写数据或代跑修复脚本。**

## 目录

| 要查什么 | 文档 |
| --- | --- |
| 已核实的表、定位键和字段关系 | [表结构速查](tables.md) |
| 备份、事务、回滚与修改后验证 | [手动维护流程](manual-workflow.md) |
| 修改任务条件后旧进度异常，如 `-11/2` | [任务旧进度修复](quest-progress.md) |
| 成就完成但称号实例缺失 | [称号缺失排查与修复](titlebook-repair.md) |

表速查目前记录任务、成就和称号相关表，不代表完整数据库结构。
后续可增加背包、邮件、角色状态等已核实的表和场景；未核实内容不先写成结论。

## 新增笔记约定

- 表结构统一补充到表速查；场景另建页面，在上表登记，避免所有案例堆进一个文件。
- 场景页写清问题表现、关联表与定位键、字段含义、修复选择、影响和验证方法。
- 公共备份与事务流程链接到手动维护流程；特殊限制写在对应场景中。
- 示例说明参数、前提和预期结果，不用一次性角色/任务编号作为通用规则。
- 只记录已确认知识；保留未知字段和实现边界，数据库操作始终由你执行。
